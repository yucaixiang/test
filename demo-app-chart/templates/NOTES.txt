  • Hello API:     http://localhost:{{ .Values.service.nodePort }}/api/hello
  • Greet API:     http://localhost:{{ .Values.service.nodePort }}/api/greet?name=YourName
  • System Info:   http://localhost:{{ .Values.service.nodePort }}/api/info
  • Prometheus:    http://localhost:{{ .Values.service.nodePort }}/actuator/prometheus

{{- else if contains "LoadBalancer" .Values.service.type }}
NOTE: It may take a few minutes for the LoadBalancer IP to be available.

Run these commands to get the external IP:
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "demo-app-chart.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo http://$SERVICE_IP:{{ .Values.service.port }}

{{- else if contains "ClusterIP" .Values.service.type }}
The application is only accessible within the cluster.

To access from your local machine, run:
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app={{ .Values.nameOverride }}" -o jsonpath="{.items[0].metadata.name}")
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 8080:8080

Then visit: http://localhost:8080
